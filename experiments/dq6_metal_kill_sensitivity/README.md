# DQ6 Metal Slime appearance / kill sensitivity v0

## 目的

アモール北の洞窟B2について公開RTA資料に「Metal Slime出現率は約20%と言われている」という参考値がある。一方、Metal Slimeは逃走するため、**出現率と1350EXPの獲得確率は同じではない**。

そこで、出現率を20%の参考値として固定し、出現時の撃破成功率を25 / 50 / 75 / 100%と振って、追加戦闘1回がEXP閾値847を跨ぐ価値を感度分析する。

公開値のprovenance:

- https://dqrta.com/data/exp01/
- https://dqrta.com/enemies/metal-slime/
- https://togoblo25.fc2.net/blog-entry-131.html

## 仮定

- Metal appearance: 20%（公開資料の概算値。厳密値ではない）
- Metal kill probability given appearance: 25 / 50 / 75 / 100%（未計測）
- Metal EXP: 1350
- Metal撃破失敗時EXP: 0（簡略化。お供撃破等は未反映）
- 非Metal時EXP候補: 19, 19, 21, 23, 24を等確率（仮定）
- 追加戦闘の正味コスト: 10秒（仮定）
- 目標EXP: 847

## 主要な結果

現在EXP=800では通常敵1戦で847へ届かないため、価値はほぼMetal撃破成功に依存する。

| Metal撃破率（出現時） | Metal EXP実効獲得率 | 10秒追加戦闘のbreak-even後続短縮 |
| ---: | ---: | ---: |
| 25% | 5% | 200.0 s |
| 50% | 10% | 100.0 s |
| 75% | 15% | 66.7 s |
| 100% | 20% | 50.0 s |

一方EXP=825では通常敵の23/24EXPでも847を跨げるため、Metal撃破率への依存が弱くなる。

| Metal撃破率（出現時） | 閾値到達確率 | break-even後続短縮 |
| ---: | ---: | ---: |
| 25% | 37% | 27.0 s |
| 50% | 42% | 23.8 s |
| 75% | 47% | 21.3 s |
| 100% | 52% | 19.2 s |

## 解釈

重要なのは数値そのものではなく、**どのEXP帯ではMetal撃破率の精度が重要で、どのEXP帯では通常戦の価値の方が支配的か**を分離できること。

- EXPが閾値から遠い: Metal撃破率の推定が重要
- EXPが閾値へ近い: 通常敵編成・戦闘時間・後続短縮量の推定が重要

したがって、エミュレータ計測を始めたら全パラメータを均等に測るのではなく、意思決定境界を動かす量から優先して計測する。
