# DQ6 early break-even experiment v0

## 目的

夢見の洞窟〜アモール北の洞窟周辺で発生する「今ここで1戦余計に狩ると、後続のレベル閾値・戦闘・稼ぎをどれだけ削れば全体で得になるか」を、実測値が揃う前でも検討できる形にする。

この実験は **実ゲームの最適policyを主張するものではない**。ROM / emulator計測前の sensitivity analysis である。

## 使用する公開チャート由来の値

- 主人公Lv7の基準EXP: 847
- アモール北の洞窟で記録されている通常敵EXP例: 19, 19, 21, 23, 24
- Metal Slime EXP: 1350

Provenance:

- https://togoblo25.fc2.net/blog-entry-131.html
- https://mamemommm.com/dq6_chart_mmm

## 未計測なので仮定する値

- Metal Slimeを含む遭遇確率
- 各通常敵の実際の出現確率
- 追加戦闘の正味時間コスト
- 閾値を跨ぐことで後続区間から削れる秒数

`run.py` の初期sliceでは、非Metal時の通常EXP候補を等確率と仮定し、Metal確率を1%, 5%, 10%, 20%と振る。追加戦闘の正味コストは10秒と置く。

これは実ゲームの遭遇テーブルを表現するためではなく、**どの未知パラメータを測れば意思決定が確定するかを可視化するため**の仮説モデルである。

## 判定量

追加戦闘1回で目標EXPを跨ぐ確率を `q`、追加戦闘の正味時間コストを `C`、閾値を跨いだことで後続区間から削れる時間を `B` とする。

単純モデルでは追加戦闘が有利になる条件は:

```text
B > C / q
```

よって `C/q` を break-even downstream saving として保存する。

## 初期結果の読み方

例として現在EXP=825、Metal確率5%、追加戦闘コスト10秒という仮定では、通常EXP 23/24のケースでも847を跨ぐため、仮説モデル上の閾値到達確率は0.43となる。したがって、847到達が後続から約23.26秒より大きく削るなら追加戦闘に期待値上の余地がある。

一方、現在EXP=800では通常敵1戦では847に届かないため、Metal確率5%ならbreak-evenは200秒になる。

これは「レベル目標の直前では通常戦にも価値が生じ、遠い状態ではMetal依存になる」という状態依存性を機械的に表現しただけであり、実際の狩る/逃げる判断は実測した戦闘時間・遭遇率・後続価値に差し替えて再計算する。
