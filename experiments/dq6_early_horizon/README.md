# DQ6 early finite-horizon policy experiment v0

## 目的

現在EXPだけでなく、ボスまでに「あと何回、狩る/逃げるを選べる機会が残っているか」が最適actionを変えることを確認する。

この実験は実測前の仮説モデルであり、DQ6実ゲームの最適routeを主張しない。

## 仮定

- target EXP: 847
- Metal確率: 5%
- Metal EXP: 1350
- 非Metal EXP候補: 19, 19, 21, 23, 24（等確率と仮定）
- fight正味コスト: 10秒
- 847未達で後続に30秒penalty
- 残り戦闘機会: 1 / 2 / 3

## 観察

このモデルでは、例えばEXP=800では残り1〜2機会なら`skip`だが、残り3機会では`fight`になる。通常敵を複数回積み上げて閾値へ届く可能性が生まれるためである。

一方、EXP=824付近では残り1〜2機会で`fight`だが、残り3機会では最初の機会を`skip`しても後から同等のpolicyを実行できるため、初手はtieとなり`skip`が選ばれる。

したがって、実ゲームでのpolicyは単なる

```text
EXP >= X なら狩る
```

では不十分で、少なくとも

```text
(current EXP, 残り経路, 残りencounter機会, 後続value)
```

に依存し得る。

## 意味

これはユーザーが想定した「イベント直前だけを局所最適化せず、その前の移動・遭遇機会まで含めて全体最適化する」構造を、最小の有限状態モデルで再現したもの。

実ゲームへ移す際は、各機会を同一分布として扱わず、map / floor / encounter table / movement costごとのmacro actionへ置換する。
